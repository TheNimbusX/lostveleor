# Курсоры v3 — согласование формы

Все шесть исходных PNG созданы через imagegen с референсами логотипа, меню и, для боевого курсора, сабли Пелага. Это высокое разрешение с прозрачным фоном; файлы пока не импортированы в Unity.

| Файл | Состояние | Основная форма |
|---|---|---|
| `pointer.png` | обычный | светлый каменный указатель |
| `move.png` | приказ идти | два следа шагов |
| `attack.png` | враг под курсором | сабля Пелага, острие — точка действия |
| `interact.png` | NPC или предмет | протянутая рука |
| `aim.png` | выбор цели способности | точный прицел |
| `blocked.png` | недоступная цель | погашенный перечёркнутый указатель |

`preview.html` показывает изображения на игровом кадре с регулировкой отображаемого размера. До замены текущих курсоров требуется художественное согласование формы и проверка уменьшенных текстур в игре.
