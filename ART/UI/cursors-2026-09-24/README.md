# Игровые курсоры

Утверждённый исходный лист: `unified-concept-v2.png`. Все пять силуэтов сделаны в одном материале: светлый камень, тонкая золотая кромка и небольшие огненные трещины. Более ранние листы в этой папке оставлены только как история вариантов.

| Файл | Когда показывается | Горячая точка |
| --- | --- | --- |
| `pointer.png` | обычное наведение, движение мышью, меню и HUD | острие (8, 3) |
| `attack.png` | враг под курсором | острие сабли (8, 4) |
| `interact.png` | объект лагеря для взаимодействия | центр (24, 24) |
| `aim.png` | допустимая цель способности | центр (24, 24) |
| `blocked.png` | недоступная цель способности | острие (8, 3) |

Готовые прозрачные PNG 48×48 лежат в `razlom/Assets/Resources/UI/Cursors/`. Команда `python tools/ui/build_cursors.py` повторяет техническую нарезку, очистку фонового alpha и уменьшение утверждённого листа. `GameCursorView` выбирает состояние, `GameCursorImporter` импортирует без сжатия и mipmaps.

Зелёный отклик ПКМ — четыре крупных штриха из одного исходника `move-order-marker-source.png`; игровая текстура лежит в `razlom/Assets/Resources/VFX/MoveOrderMarker.png`. Штрихи резко сходятся к месту клика, отскакивают и расходятся при затухании. `CombatIndicators` размещает каждый штрих на маленькой сетке, повторяющей высоту поверхности под ним, включая мост. Небольшой отступ от поверхности и сдвиг глубины в шейдере не дают метке проваливаться в настил. `move-order-motion-preview.png` показывает четыре фазы движения.
