## Что было не так (OKLab: L — светлота, C — насыщенность, h — тон)

| | Хранитель было | стало | Корнехват | семья леса |
|---|---|---|---|---|
| листва, тон h | 110° ± 8.6 (холодная, разношёрстная) | 105° ± 4.7 | 104° ± 4.0 | 101–108°, ± 2.6–5.9 |
| листва, C | 0.069 | 0.090 | 0.092 | 0.069–0.088 |
| листва, L | 0.372 (темнее всех) | 0.462 | 0.488 | 0.41–0.43 |
| кора, L | 0.397 | 0.452 | 0.466 | 0.40–0.44 |
| кора, C | 0.069 (рыжая, «загар») | 0.061 | 0.060 | 0.053–0.072 |
| всё тело L p10/p50/p90 | 0.260/0.386/0.550 | 0.295/0.452/0.582 | 0.303/0.465/0.594 | |

- Кора: средние тона приглушены (насыщенность ×0.75–0.93 по полосам светлоты), свет — к кремово-жёлтому,
  как кончики пластин у Корнехвата (тон −4…+5°). Рыжий «загар» ушёл в серо-коричневый.
- Листва: из холодной тёмной зелени в жёлто-зелёную, как у всей семьи (тон −5…−8°, C ×1.2–1.3).
- Светлота поднята на 80% пути к эталону, не на 100%: без высветления. Контраст сохранён —
  p90−p10 было 0.290, стало 0.287 (Корнехват 0.291), щели и прожилки остались тёмными.
- Читаемость на земле арены (тот же рендер): медиана ΔE тела до земли 0.085 → 0.107
  (Корнехват 0.140); пикселей тела, сливающихся с землёй (ΔE < 0.06), 32% → 21% (Корнехват 16%).
