Звуки Плюй-плода и сигналов — кандидаты 26.09

Всё собрано из своей семьи (HitBody, Kill, Whoosh, Cast, HitMetal, Dissolve, шаги, записи сабли Attack_01..05) — высота, фильтры, огибающие, слои. Выбор ставится командой python build-bud-sfx.py --install volley=b fruit=a ...

Залп Плюй-плода

Бутон раскрывается (0,8 с) и выпускает 5 плодов через 0,2 с. В игре раскрытие и каждый хлопок звучат по своим событиям.

A — листва и вдох, мягкое «пок» — сейчас в игре

B — скрип коры, глухое «тумп»

C — воздушный вдох, «пфф-ток», хлопки идут вверх

Падение плода

Мягкий сочный хлопок в точке падения; звучит на каждом из пяти плодов.

A — мягкий шлепок с брызгами — сейчас в игре

B — глухой плюх

C — хрусткая кожура

Боль бутона

Тело бутона при ударе героя (сталь сабли звучит отдельно, как у всех).

A — сочное «тук» и дрожь листьев — сейчас в игре

B — удар и хруст

C — высокий «ток» и скрип стебля

Смерть бутона

От удара до касания земли (~1 с); осыпание потом — общее.

A — удар, сдувание, осыпание листвы, касание — сейчас в игре

B — глухой удар, долгое шуршание

C — сочный удар с каплями, выдох, касание

Сигнал крупного телеграфа

Только в начале крупных: таран Камнекопыта, прыжок/коготь (и будущий вой) Вендиго, залп Плюй-плода.

A — «вдох» — обратный свист — сейчас в игре

B — двойной стук «тук-тук»

C — тёмный звон навстречу

Замах хранителя (очень тихо)

Обычный замах хранителя больше не зовёт общий сигнал. Вариант «тишина» тоже годится: --install swing=none.

A — тяжёлый медленный свист — сейчас в игре

B — взмах сабли ниже

C — воздушный выдох
