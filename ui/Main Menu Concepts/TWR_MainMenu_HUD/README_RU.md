# THE WAR REMAINS — Main Menu HUD / v1.0

## Состав
Пак содержит только PLAY, настройки и выход. Новых разделов, валют, профилей,
баннеров и нового логотипа нет. PNG/Buttons — готовые кнопки; PNG/Components —
плашки, рамки и эффекты фокуса; PNG/Icons — отдельные значки;
PNG/Labels — отдельная надпись PLAY. Preview — два обзорных изображения.
manifest.json — точные имена, размеры и пример расположения на исходном фоне.

## Состояния
normal — обычное;
hover — наведение/активный выбор;
pressed — нажатие;
disabled — недоступно.
Состояния одной кнопки имеют одинаковые размеры и прозрачные поля.
Переключать следует соответствующие изображения, а не растягивать каждое по видимым пикселям.

## Два способа сборки
1. Быстрый: использовать три изображения btn_play_*, btn_settings_* и btn_exit_*.
   Надпись и иконки уже включены. Не дублировать их отдельными слоями.
2. Послойный: primary_plate_* + icon_play_gold + надпись PLAY;
   diamond_plate_* + icon_settings_gold / icon_exit_gold.
   primary_plate уже содержит рамку. Раздельные primary_fill + primary_frame
   нужны только для независимого оформления слоев и используются ВМЕСТО primary_plate.

Для локализации можно использовать текст движка вместо PNG-надписи.
Белые варианты иконок и надписи предназначены для окрашивания.
Файлы шрифтов не входят в пакет.

## Размеры
Primary — 1024 × 320 px. Diamond — 256 × 256 px.
Иконки — 192 × 192 px. Отдельная надпись PLAY — 336 × 168 px.
btn_play_reference_native.png — исходная кнопка 400 × 125 px без окружения;
она добавлена для точного сопоставления с утвержденным меню.
Плашка PLAY получена из утвержденного изображения: фон удален, надпись отделена,
текстура очищена. Увеличенный экспорт не является новым нативным 4K-рисунком.
Ромбы и значки подготовлены отдельно, без запеченного изображения пейзажа.

## Фон и логотип
Они остаются в ранее подготовленном фоновом изображении/видео и не входят в PNG HUD.
Preview/menu_preview.jpg использует ваш фон с исходным логотипом без перерисовки.
Пак не содержит анимацию фона.

## Прозрачность и расположение
Все игровые элементы — 8-bit RGBA PNG. Черная подложка не запечена.
Превью на темном фоне и JPG с окружением — только для просмотра, не игровые спрайты.
Рекомендуется сохранить прозрачные поля спрайтов, чтобы состояния не прыгали.
Координаты в manifest используют начало слева сверху. При переводе в систему с
началом снизу вертикальную координату центра требуется инвертировать.

## Ограничения передачи
Это набор изображений, не готовая сцена, prefab или Unity package.
Программная проверка размеров, RGBA, целостности файлов и единых размеров
состояний выполнена; проверка в Unity Editor в этой сессии не выполнялась.
Графические состояния не реализуют нажатие/фокус сами по себе — их выбирает интерфейс игры.
