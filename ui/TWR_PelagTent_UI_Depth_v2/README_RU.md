# THE WAR REMAINS — UI палатки, Depth v2

Этот ZIP заменяет прежние плоские панели и ячейки. Графика — отдельные RGBA PNG.
Это не работающий Unity-префаб и не 3D-модели. Проверка в Unity Editor не проводилась.

## Содержимое
- PNG/Panels: шесть размеров панелей, рамки, поверхности, отдельные тени; также заготовка для 9-slice.
- PNG/Slots: нарисованные углублённые ячейки и состояния / редкости.
- PNG/Buttons: исходная основа главной красной кнопки из кита главного меню, вторичная кнопка, кнопки функций. Состояния normal, hover, pressed, disabled.
- PNG/Icons: рельефные золотые значки функций и пустых слотов. Это не иллюстрации конкретных предметов.
- PNG/ItemArt: пять небольших образцов предметов, извлечённых из вашего ранее приложенного макета. Это не новые детализированные иллюстрации.
- PNG/Components: ромбовая основа, нарисованный ромб, разделитель, трек и заполнение прогресса, расположение основных панелей без текста.
- Preview: концепт, обзор настоящих файлов и сравнение до/после.
- manifest.json: действительные размеры каждого PNG и назначение.
- layout_1920x1080.json: демонстрационная компоновка на 1920×1080.

## Сборка
Рамка и поверхность уже объединены в *_filled.png. Для простого размещения достаточно этого файла.
Для раздельного оформления используйте *_surface.png и *_frame.png; *_shadow.png кладите под ними.
Не накладывайте одновременно *_filled.png и отдельные frame/surface: получите двойной слой.
Рекомендуемые borders заготовки panel_9slice — 69 px с каждой стороны. Это отправная точка; их нужно проверить в целевой версии движка.
Декоративный ромб размещается отдельным объектом, чтобы не тянуть его при изменении размеров.
Обычные большие панели лучше использовать в указанных пропорциях: их рамки уже собраны без растяжения углов.
Состояния каждой кнопки имеют одинаковый холст и выравнивание.
Текст, счётчики и цифры выводите отдельно в движке. В PNG кнопок текста нет.
48 ячеек — это повторение одного спрайта, не 48 уникальных изображений.
Иллюстрация персонажа и палатка в концепте использованы из ваших изображений; новый логотип и гербы не создавались.
В архиве только интерфейсные элементы и превью: фон и модель персонажа не являются новыми игровыми ассетами.

## Важно
Некоторые элементы нарезаны из сгенерированного рисованного мастер-арта и затем собраны/масштабированы. Увеличенный размер PNG не означает новую детализацию исходника.
Наведение/нажатие/недоступность являются графическими вариациями; анимации и логика переходов здесь не реализованы.
Макет использует условные предметы, статистику и валюты; это не изменение игровых систем.
Нельзя утверждать, что набор проверен в Unity или готов к выпуску: тестируются только сами изображения и структура ZIP.
