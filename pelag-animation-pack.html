02 · Контракт

Тайминги, которые задаёт код

Симуляция идёт 30 тиков в секунду, и все игровые длительности заданы в тиках. Клип обязан уложиться в них, а не наоборот — иначе урон и картинка разъедутся.

ЧтоТиковСекундСмысл
Замах автоатаки120.400от начала взмаха до урона
Цикл автоатаки240.800при базовой скорости 1.25/с
Контакт Вихря100.333от каста до урона по кругу
Полёт Броска якоря80.267тело едет по цепи
Рывок Подсечки100.333врагов волочит к игроку
Прыжок Шага по цепи50.167один прыжок, всего до 4
Замедление в способности240.800идёт вдвое медленнее
Разгон тела30.100до полной скорости
Торможение40.133до остановки
Почему замах именно 12 и почему его нельзя просто уменьшить

Двенадцать тиков — это слепок анимации, а не решение баланса. CharacterAnimatorView разгоняет клип по фазам так, чтобы авторская поза контакта пришлась ровно на этот тик:

0.12 с на скорости 0.76, дальше до контакта на 1.82
0.12 × 0.76 + (0.40 − 0.12) × 1.82 = 0.601
0.601 ÷ 1.633 с (клип 49 кадров) = 0.368  →  AttackAContactNormalized = 0.37

Меняешь клип — меняется и это число. Пока оно не пересчитано, урон приходит, когда клинок ещё на полпути. Так уже ломали один раз: константу поменяли, клип нет.

Правильный порядок ровно такой: сначала клипы, потом фазовые скорости, и только потом константа замаха.

06 · Работа

Blender: с чего начать

  1. Импорт

    File → Import → FBX (.fbx)
Справа в панели импорта:
  Armature → Automatic Bone Orientation → СНЯТЬ галку

    Без снятой галки Blender перестроит ориентации костей по-своему, и на экспорте обратно риг не совпадёт с тем, что ждёт Unity.

  2. Частота кадров — до всего остального

    Output Properties (иконка принтера справа)
  Frame Rate → 30
    На этом уже спотыкались

    Клипы Mixamo приходят в 60 fps. Если не переключить сцену на 30 до правок, все длительности уедут ровно вдвое, и обнаружится это уже в игре.

  3. Найти анимацию

    Сменить область на Animation (вкладки сверху)
  Dope Sheet → режим Action Editor
  Экшен уже подцеплен к арматуре

    Внизу видна шкала кадров, слева — список костей. Работать удобнее, выделив всю арматуру в Pose Mode клавишей A.

  4. Понять, где контакт

    Прокрути клип и найди кадр, на котором клинок или якорь достигает цели. Запиши его номер — он понадобится и при правке, и при сдаче.

    Для существующих комбо это кадр, дающий нормализованные 0.37 и 0.225 — то есть примерно 18-й из 49 у SaberCombo.

07 · Ремесло

Семь приёмов

Порядок не случаен: первые три чинят большинство клипов Mixamo, остальные добавляют то, чего в них не было изначально.

1. Срезать провисание

У клипов Mixamo длинные вход и выход — они сделаны для витрины, а не для боя.

Pose Mode → A (выделить все кости)
В Dope Sheet выделить лишние ключи в начале
X → Delete Keyframes
Оставшиеся сдвинуть к нулю: G → X → ввести смещение

2. Сжать до контакта, растянуть после

Это то, что делает удар весомым: быстрый разгон и медленная оттяжка.

Выделить ключи ДО контакта  → S → 0.6 → Enter
Выделить ключи ПОСЛЕ        → S → 1.3 → Enter

Курсор при масштабировании работает как точка опоры — поставь его на контактный кадр, иначе поедет весь клип.

3. Интерполяция

По умолчанию Bezier смазывает удар в кисель.

Все ключи         → T → Bezier
Ключи у контакта  → T → Linear

4. Добавить замах

Вес удара живёт в кадрах до контакта, а не после. Если клип бьёт без подготовки, его не спасёт никакая оттяжка.

Встать за 3 кадра до начала движения
Повернуть Spine и Chest на 8–12° ПРОТИВ направления удара
I → Rotation

5. Задержать пик

Hades и Hell Clock держат контактную позу лишний кадр — именно это читается как «попал».

Выделить контактный ключ → Ctrl+C
Встать на +1 кадр → Ctrl+V

6. Замкнуть цикл

Для Idle, CombatIdle, ChainStep и всех strafe.

Скопировать первый ключ в последний кадр
Шов должен сойтись ТОЧНО — иначе на стыке будет рывок

Проверять зацикливание надо проигрыванием минимум трёх повторов подряд: один проход шва не показывает.

7. Развести верх и низ

В контроллере есть отдельные триггеры LowerAttackA, LowerAttackB, LowerHeavyAttack — то есть нижняя часть тела может жить своей жизнью.

Практический смысл: ноги продолжают бег, пока руки бьют. Для этого клип удара делается так, чтобы ключи ниже пояса в нём отсутствовали — тогда их подставит слой локомоции.

08 · Передача

Экспорт и импорт

Из Blender

File → Export → FBX (.fbx)

Include → Limit to: Selected Objects (арматура + меш)
Armature → Add Leaf Bones → СНЯТЬ
Bake Animation → включить
  Simplify → 0
Transform → Apply Scalings: FBX All
Меш экспортировать обязательно

Соблазн выгрузить «только анимацию» велик, но FBX без скиннутого меша заставляет Unity восстанавливать скелет из первого кадра, и bind pose ломается. Unity всё равно возьмёт из файла только AnimationClip — меш нужен ради корректного рига.

В Unity

Выдели FBX → вкладка Animation в инспекторе.

ПолеЗначениеЗачем
Root Transform Position (Y)Bake Into Poseиначе клип потащит персонажа вверх
Root Transform Position (XZ)Bake Into Poseположение решает симуляция, не клип
Root Transform RotationBake Into Poseповорот тоже за симуляцией
Loop Timeпо клипувкл. для Idle, strafe, ChainStep
Start / Endкадрыдешёвая обрезка без Blender

Start/End — самый быстрый способ поправить тайминг: обрезал начало, контакт уехал раньше. Годится для проб; для чистового результата всё же Blender, потому что обрезка не добавит замаха, которого в клипе нет.

09 · Границы

Что ломает всё

Не переименовывать кости

Риг — Mixamo, префикс mixamorig:, 65 костей. Ретаргет держится на именах: переименовал одну — клип молча перестанет двигать эту часть тела.

Не двигать Hips по XZ

Положение персонажа решает симуляция. Клип, который везёт тело сам, разъедет картинку с логикой: урон придёт туда, где персонаж по мнению кода, а не туда, где он на экране.

Правило поддерживается настройкой импорта Bake Into Pose — но полагаться только на неё не стоит, потому что она снимается одним кликом.

Не менять длительности, не сказав

Каждая цифра из раздела 02 живёт в коде. Клип короче или длиннее заявленного — и способность либо обрывается, либо тянет паузу после того, как гейплей уже кончился.

Сокеты, к которым цепляется снаряжение

mixamorig:RightHand — сабля. mixamorig:Hips — якорь на поясе. Отдельных костей-сокетов у этого рига нет, пропсы садятся прямо на кости; их положение настраивается в инспекторе ArenaView ползунками, а не в Blender.

10 · Приёмка

Как сдавать

Файлы — в razlom/Assets/Resources/Characters/Pelag_v5/Mixamo/, имена по образцу Pelag_MX_AnchorDraw.fbx.

С каждым клипом — два числа: длина в кадрах и кадр контакта. Без них я не могу пересчитать фазовые скорости, а без пересчёта удар разъедется с уроном.

Проверка перед сдачей. В корне проекта:

cd C:\Users\d.grab\Desktop\the-game
.\run-tests.ps1

Должно быть 203/203 зелёных и «Game.View и Editor: собираются». Покраснело — задето что-то, чего задевать не следовало.

Порядок, если делать по одному

1. AnchorDraw и AnchorStow — иначе якорей в кадре два.
2. Два Recovery — самое заметное на глаз за наименьшие деньги.
3. SaberA_to_B и Ability_to_Run — связки, которые чинят «щелчки».
4. CombatIdle и два Idle_Break — персонаж перестаёт быть манекеном.
5. Всё остальное.
