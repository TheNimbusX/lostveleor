# Алхимик: контракт игровой логики с UI

Игровая логика готова в `Camp.Potions.cs`, `Camp.Alchemy.cs` и `Simulation.PotionEffects.cs`. UI лагеря оформляет другой агент. Модель NPC и авторскую сцену не менять.

- При открытии разговора вызвать `Camp.MeetAlchemist()` один раз (текущий `ShowAlchemist` это уже делает). Показать оба заказа со статусами `Camp.AlchemyStatus(AlchemistOrder.Resin/Surge)`: `Available`, `Accepted`, `Ready`, `Unlocked`. `Hidden` существует лишь до первого разговора.
- Кнопки: `AcceptAlchemyOrder`, `TurnInAlchemyOrder`, `ExchangeRareForResin(bagSlot)`, `ExchangeShardsForSurge()`. Возвращаемый `AlchemistActionResult` — причина отказа. Для обмена вещью/осколками показать подтверждение **до** вызова: успешный вызов уже атомарно списывает цену и открывает рецепт. Вещь допускается только `Magic`, в сумке и без отметки «беречь».
- В лавке 6 товаров: прежние ID 0–3, `LivingResin=4`, `LavidiumSurge=5`. `Camp.PotionUnlocked(kind)` управляет замком; `TryBuyPotion(kind)` сообщает `PotionPurchaseResult`. Оба новых стоят 70 золота. Запас `PotionCount`, выбор `SelectedPotion(0/1)`, ручной выбор `SelectPotion`, перебор ПКМ `CyclePotion(slot)`. Слоты остаются HP и лавидий, третьего нет. Нулевой запас визуально серый и не заменяется автоматически.
- Для применения не собирать бит вручную: `Camp.PotionInputBit(kind)` даёт маску для `InputFrame.PotionMask`. Биты 4/5 по-прежнему переключают слот ПКМ. `TickDriver.Potions` уже использует этот helper для клавиш, ЛКМ и крестовины геймпада.
- Таймеры эффектов: `session.ActiveSim.ResinTicksLeft` и `SurgeTicksLeft`, по 30 тиков на секунду, максимум 180. Показать два разных мини-значка рядом с текущими состояниями героя, не превращать их в дополнительные быстрые слоты. Пауза не вызывает тик, поэтому отсчёт стоит.
- В бою UI может показывать `session.AlchemyCleanLevelInProgress`, а завершение заказа приходит через `AlchemyStatus == Ready`. Статус сохраняется сразу; всплывающее уведомление о выполнении можно привязать к его изменению.

Иконки двух новых бутылок готовит владелец. Арт-бриф: форма «Живицы» приземистая, широкая, янтарно-смоляной акцент; «Порыв» вытянутый, динамичный силуэт, бирюзово-синий акцент. Читаемые разные силуэты при размере быстрого слота, без белого контура и без светящейся плоской обводки. До передачи файлов допустим подписанный временный вариант из текущих бутылок; не выдавать его за финальный арт.

Пока финальный UI собирается отдельно, в редакторе работает `Разлом → Алхимик → Тестовый стенд`. Он запускает `SampleScene` с временной IMGUI-панелью (F10), отдельной сессией без записи сохранения, тестовыми деньгами/осколками/редкой вещью и обычным боем с гарантированным Лесным бутоном. После подключения авторского интерфейса удалить стенд и его меню; игровую логику оставлять.

В обычной редакторской игре разговор с NPC алхимика открывает ту же временную панель, но с настоящим прогрессом лагеря: без тестовых ресурсов и кнопки гарантированного боя. Это мост к игровому тесту, пока авторский UI не готов. После его подключения убрать и этот временный вызов.
